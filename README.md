# 🧠 SaaS Lab: Aprendizaje Modular Ético

Este repositorio contiene una serie de mini-proyectos diseñados para aprender y validar los fundamentos técnicos de un SaaS moderno. Cada módulo aborda un tema específico (base de datos, API, autenticación, frontend, integración) con enfoque práctico, ético y documentado.

## 🎯 Objetivos por módulo

| Módulo | Tema | Objetivo |
|--------|------|----------|
| 01 | Modelado de base de datos | Aprender SQLAlchemy, relaciones y CRUD |
| 02 | API REST con FastAPI | Construir APIs limpias, tipadas y documentadas |
| 03 | Autenticación JWT | Implementar login, roles y protección de rutas |
| 04 | Frontend con React | Visualizar datos, manejar sesión y conectar con API |
| 05 | Integración y Deploy | Consolidar todo en un SaaS funcional y desplegado |

## 🧰 Tecnologías

- **Backend:** Python, FastAPI, SQLAlchemy, PyJWT
- **Frontend:** React, Vite
- **Base de datos:** PostgreSQL (SQLite para pruebas)
- **Testing:** Pytest, React Testing Library
- **Automatización:** n8n
- **Deploy:** Docker, Render, Vercel
